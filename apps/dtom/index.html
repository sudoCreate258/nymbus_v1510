Camera won't start?
  1. Open the page from http://localhost, not by double-clicking: in this folder run python -m http.server 8765, then open http://localhost:8765.
  2. Allow the camera when the browser asks. If you blocked it earlier: click the lock/camera icon in the address bar → Camera → Allow, then reload.
  3. Windows: Settings → Privacy & security → Camera → turn on Camera access and Let desktop apps access your camera.
  4. Close Teams/Zoom/the Camera app — Windows lets only one app use a webcam at a time.
  5. Two USB cameras on one hub can fail together; plug the external one into a different port.
